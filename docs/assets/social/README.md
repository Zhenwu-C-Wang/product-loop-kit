## Usage

Use this image when introducing Product Loop Kit as a plain-file product artifact layer for AI coding agents.

Do not present it as a product UI screenshot. It is a conceptual illustration for the product loop:

external feedback -> product vision -> product spec -> eval plan -> agent task -> PR evidence -> developer review -> decision log.
